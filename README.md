# Mundo-de-los-Monstruos

## Descripción

Este proyecto consiste en una página web creada con **HTML y CSS**. La página presenta un monstruo llamado Harry el Rápido.

## Características

* Página principal con un título y un banner.
* Monstruo creado con CSS.
* Botones interactivos.
* Sección con información sobre el monstruo.
* Página de contacto con un formulario.
* Diseño adaptable a ordenadores, tablets y móviles.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## Cómo abrir el proyecto

1. Descarga o copia los archivos del proyecto.
2. Abre la carpeta del proyecto.
3. Abre el archivo `Inicio.html` en tu navegador.
